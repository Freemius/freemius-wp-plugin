# Feature

Start **new implementation work** on a topic branch. Match the user’s rough topic to the **Roadmap** section in [`README.md`](../../README.md) when possible, then create `feature/<slug>` and outline next steps.

Follow every step in [`.cursor/skills/feature/SKILL.md`](../skills/feature/SKILL.md).

**Not for** filing GitHub issues (`/issue`) or cutting releases (`/do-release`).

User passes a rough name after the command (e.g. `/feature pricing tables` or `/feature settings page`). If the topic is missing, ask once for a short name, then continue.
