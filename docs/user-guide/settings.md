# Settings

Global plugin settings live at **Settings → Freemius** in the WordPress admin.

Configure:

- **Freemius API token** — required for product and plan data
- **Editor defaults** — default `product_id` and `public_key` inherited by scopes on the page

Page- and block-level settings override these defaults. See [Configuration scopes](button.md#configuration-scopes) on the button guide.
