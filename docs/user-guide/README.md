# Overview

Freemius for WordPress is a toolkit to help you sell products on your WordPress site.

## How it works

The plugin uses the Freemius API to fetch product data and display it in the block editor. You can add Freemius Checkout to any button in your content and configure pricing with **scopes** — nested settings on groups, columns, and buttons.

## Requirements

- WordPress 6.7+
- Freemius account
- Freemius product
