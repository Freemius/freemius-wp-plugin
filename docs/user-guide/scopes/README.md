# Scopes

The plugin lets you create multiple **scopes** for your product on a single page. Each scope can have different pricing and checkout buttons.

A scope can be enabled on these blocks (or their children):

- Group Block
- Columns Block
- Column Block
- Button Block

![Freemius checkout enabled on a scoped block in the editor](../../assets/scope-enable-checkout.png)

Each scope inherits properties from its parent scope. The outermost scope inherits defaults from **Editor Settings** (global).
