# Field mapping

Map plan fields from your Freemius product to block content inside a scope.

## Blocks that receive mapped data

- Paragraph Block
- Heading Block
- Button Block

## Supported fields

- Title
- Description
- Price
- Licenses (1, 2, 3, Unlimited)
- Billing Cycle (Monthly, Yearly, Lifetime)

Scoped blocks show a purple outline; mapped fields use a dotted outline:

![Pricing layout with Freemius scope and field mapping outlines](../../assets/scope-pricing-mapped.png)

Configure mappings in the block sidebar under **Freemius** when a scoped block is selected.
